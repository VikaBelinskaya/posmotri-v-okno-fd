# Проектная работа "Посмотри в окно"

В этом проекте я оформила стили к сайту так, чтобы интерфейс соответствовал макету проекта.
На практике потренировалась стилизовать формы и их состояния.

## Суть проекта

1. При инициализации страницы приложение автоматически отправляет запрос к API за видеоконтентом и отображает начальную подборку результатов.
2. После отправки формы система извлекает указанные параметры (город и время суток), на их основе формирует запрос с нужными фильтрами.
3. Данные, полученные от API, преобразуются в карточки; при этом первое видео из списка сразу воспроизводится в плеере.
4. При клике на карточку контент в основном плеере меняется — туда загружается видео, соответствующее выбранной карточке.
5. Кнопка «Показать ещё» инициирует подгрузку следующей порции результатов — если для текущего запроса доступна следующая страница данных.
